# Componentes do Projeto

## 1. Unidade de controle

| Componente | Quantidade | Função |
|---|---:|---|
| Arduino Uno | 1 | Controlar o sistema |
| Servo motor | 1 | Movimentar o disco representando Sol e Lua |
| Botão START | 1 | Iniciar a demonstração |
| Botão STOP | 1 | Encerrar a demonstração |

## 2. Sistema de iluminação

O planejamento original previa **46 LEDs**, distribuídos pelo modelo do corpo humano.

| Tipo de LED | Quantidade planejada |
|---|---:|
| Azul 3 mm | 20 |
| Branco 3 mm | 20 |
| Amarelo 5 mm | 3 |
| Branco 5 mm | 3 |
| **Total** | **46** |

### Demonstração física

Na versão final apresentada na feira, 10 LEDs estavam funcionando:

- 3 LEDs amarelos de 5 mm;
- 3 LEDs brancos de 5 mm;
- 4 LEDs adicionais.

Os 46 LEDs representam o planejamento completo do projeto, não a quantidade que funcionou na demonstração final.

## 3. Materiais de montagem

- Protoboard;
- Fios jumper;
- Resistores utilizados na montagem;
- Fonte externa (power bank) para alimentação do servo motor.

## 4. Observações

O servo motor foi alimentado separadamente do Arduino, com o GND compartilhado entre os circuitos.

A montagem foi desenvolvida para demonstrar visualmente a relação entre a iluminação, a alternância entre dia e noite e a produção de melatonina.

**Observação:** a versão demonstrada foi um protótipo educacional, e não um equipamento médico.
